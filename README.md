## Work Process Summary
During this assignment, I created and styled web forms using HTML5 and Bootstrap 5:
1. Built a basic HTML form with standard built-in validation attributes (`required`, `type="email"`, `minlength`, `maxlength`).
2. Styled the contact form using Bootstrap 5 classes, responsive grid layout, and added validation feedback messages (`valid-feedback` / `invalid-feedback`).
3. Implemented an advanced registration form with various input types (passwords, radio buttons, checkboxes, select) and added custom JavaScript validation to ensure password matching.
